# FinFlow category icon preview

Source: [Phosphor Icons](https://phosphoricons.com/) — Duotone weight.
License: MIT. See `LICENSE-PHOSPHOR.txt` in this directory.

This is a preview set only. The current category implementation has not been
switched to these files yet.

## Expense (24)

Food, Groceries, Transport, Fuel, Rent, Utilities, Bills, Internet & Phone,
Shopping, Clothes, Beauty, Entertainment, Travel, Education, Fitness, Health,
Pets, Gift, Donation, Subscription, Insurance, Loan Payment, Service, and
Other Expense.

## Income (12)

Salary, Bonus, Business, Freelance, Investment, Interest, Rental Income, Gift
Received, Refund, Cashback, Allowance, and Other Income.

## Goals (14)

Emergency Fund, Home, Vehicle, Travel, Education, Technology, Wedding, Family,
Health, Business, Investment, Retirement, Shopping, and Other Goal.

Goal SVG files are wired through the dedicated `GoalCategory` model and used
throughout Goal creation, cards, details, and sheets. Open `goal-preview.png`
to inspect the complete set.

Open `category-preview.png` for a quick visual comparison, or inspect the SVG
files inside the `expense` and `income` folders.
