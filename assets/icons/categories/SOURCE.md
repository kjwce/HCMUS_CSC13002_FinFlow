# Category icon source

- Icon set: Phosphor Icons
- Styles: Regular, Duotone, and Fill
- Source: https://github.com/phosphor-icons/core
- Source commit: `2b75f3ad12b420c9504ef05df8d2564a28f8500e`
- License: MIT; see `_PHOSPHOR_LICENSE.txt`

The filenames use FinFlow category names and are split by the `expense_` and
`income_` prefixes. Regular icons are stored in this directory; Duotone icons
are stored in `duotone/`; Fill icons are stored in `fill/`. The SVG artwork
itself is unchanged from the pinned Phosphor Icons source commit.
